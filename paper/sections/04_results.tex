\section{Results}
Cuts flow: 7143 $\rightarrow$ 6873 ($z$) $\rightarrow$ 2465 retained (2422 mask-classified + 43 outside search radius; 4408 fall outside the SDSS DR7 footprint entirely). Cosmo SNe \NCosmo: void \NVoidCosmo, wall \NWallCosmo\ (\NShellCosmo\ shell, \NOutCosmo\ outside; Table~\ref{tab:counts}). Observed void fraction $\NVoidCosmo/\NCosmo=0.060$ versus randoms $0.190$: apparent (uncorrected) void/wall ratios \RRall\ all, \RRia\ Ia-only (\NIaVoid/\NIaWall), \RRcc\ CC-only (\NCCVoid/\NCCWall); Poisson+Monte Carlo rel.\ err $0.09$--$0.21$. No efficiency or host-mass correction applied, so these are apparent deficits in a flux-limited sample, not intrinsic rates. Table~\ref{tab:counts} sums exactly; shell/outside rows are tabulated, not dropped. Void holds \NIaVoid\ SN Ia (subtype audit clean for the HR arm via BTS+DR2 strings (TNS-key join pending for counts only)). Volume slice $z\le0.06$: 1270 SNe total (69 void, 93 shell, 1088 wall, 20 outside; 755 Ia with 46 void); apparent slice ratios $0.23$ all, $0.26$ Ia (redshift slice only, still flux-limited, no efficiency correction). Threshold grid (SNe): 0.6:56, 0.7:88, 0.8:142, 0.9:220, 1.0:329, 1.1:531. Redshift stability $z_{\min}$ 0.01:142, 0.02:135, 0.025:130, 0.03:126 void. Void median $z$ 0.064 versus wall 0.056 confirms Malmquist gradient. First blinded DR2 Hubble test (ZTF DR2 SALT2, snia-cosmo+norm+quality cuts, $N=396$ with 31 BTS-$z$ void; unblinded 2026-10-01 per protocol; errors include Ia intrinsic scatter $0.12$ mag): raw void--wall $\Delta_{\rm HR}=+0.057\pm0.026$ (stat), mass+$z$ matched $+0.023\pm0.034$ (27 voids), joint mass slope $-0.065\pm0.011$ (linear) with residual void offset $+0.037\pm0.036$ (mass-step branch $+0.031\pm0.037$ agrees; unblinded 2026-10-01 with differences unchanged from blinded values: null concluded, 95\% limit $0.07$ mag). Relabeled with precise DR2 redshifts (BTS $z$ errors reach $0.026$), 10/31 BTS-void Ia remain void: matched $\Delta_{\rm HR}=+0.056\pm0.059$ ($n=10$), consistent with the BTS-$z$ result at lower precision. Flips concentrate at high BTS $r/R_{\max}$ (mean $0.64$ vs $0.52$ kept), i.e.\ boundary blur, not core contamination. Full-volume DR2 cross-check (all DR2 cosmo-norm-quality Ia with DR2 redshifts, $z<0.114$, in-mask: 752 total, 37 void): matched $\Delta_{\rm HR}=+0.034\pm0.030$ ($n=33$), consistent with the BTS-gated primary.
