We cross-match VAST VoidFinder SDSS DR7 (1163 voids, $z<0.114$, median $R_{\max}=11.9\,h^{-1}{\rm Mpc}=17.6\,{\rm Mpc}$, median $R_{\rm eff}=15.5\,h^{-1}{\rm Mpc}=22.9\,{\rm Mpc}$) with ZTF Bright Transient Survey supernovae using a Planck18-consistent ($h=0.6766$) KD-tree ball query with 1-deg SDSS mask (quantized; edge test in text). Of 6873 BTS transients at $z=0.01$--$0.114$, 2465 are retained (2422 mask-classified: 147 void ($r/R_{\max}<0.8$), 195 shell ($0.8$--$1.0$), 2080 wall; 43 outside search radius, of which 42 are cosmo SNe and 1 is a TDE). Cosmo SNe (TDE/Ca-rich/other excluded): 2367 total, 142 void (118 SN Ia; subtype audit clean for the HR arm via BTS+DR2 strings (TNS-key join pending for counts only)). Volume slice $z\le0.06$ (redshift slice only, still flux-limited): 1270 SNe total, 69 void (46 Ia). Hubble test (ZTF DR2 SALT2; blinded BTS-gated primary, $n=27$ matched: $+0.023\pm0.034$ mag; post-unblinding full-volume DR2-$z$ cross-check, $n=33$: $+0.034\pm0.030$ mag, $\pm0.042$ with systematics), consistent with zero (two-sided 95\% interval $[-0.05,+0.12]$ mag). Analysis developed blinded and unblinded 2026-10-01 per protocol with differences unchanged. Catalog, randoms design and pipeline are archived in the public release. A CHIME FRB stacking forecast in the same void geometry is given as an outlook.
