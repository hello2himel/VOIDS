We cross-match VAST VoidFinder SDSS DR7 (1163 voids, $z<0.114$, median $R_{\max}=11.9\,h^{-1}{\rm Mpc}=17.6\,{\rm Mpc}$, median $R_{\rm eff}=15.5\,h^{-1}{\rm Mpc}=22.9\,{\rm Mpc}$) with ZTF Bright Transient Survey supernovae using a Planck18-consistent ($h=0.6766$) KD-tree ball query with 1-deg SDSS mask (quantized; edge test in text). Of \NBTS\ BTS transients at $z=0.01$--$0.114$, \NRETAINED\ are retained (\NCLASSIFIED\ mask-classified: \NVoidAll\ void ($r/R_{\max}<0.8$), \NShellAll\ shell ($0.8$--$1.0$), \NWallAll\ wall; \NOutsideAll\ outside search radius, of which \NOutCosmo\ are cosmo SNe and 1 is a TDE). Cosmo SNe (TDE/Ca-rich/other excluded): \NCosmo\ total, \NVoidCosmo\ void (\NIaVoid\ SN Ia; subtype audit clean for the HR arm via BTS+DR2 strings (TNS-key join unavailable; counts arm carries BTS-string audit only)). Redshift slice $z\le0.06$ (still flux-limited): \NSlice\ SNe total, \NSliceVoid\ void (\NSliceIaVoid\ Ia). Hubble test (ZTF DR2 SALT2, full-volume DR2-$z$ primary, $n=33$ matched: $+0.034\pm0.030$ mag ($\pm0.042$ with systematics); BTS-gated branch, $n=27$: $+0.023\pm0.034$ mag), consistent with zero (two-sided 95\% interval $[-0.05,+0.12]$ mag). Analysis developed blinded and unblinded 2026-10-01 per protocol with differences unchanged. Catalog, randoms design and pipeline are archived in the public release. A CHIME FRB stacking forecast in the same void geometry is given as an outlook.
